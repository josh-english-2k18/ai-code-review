# Reconcile review reports

You are reconciling prior review reports into a single set of challenges the author can verify.

Combine challenges only when they concern the same behavior, conditions, and review target. Confirm that working-tree reports examined the same files, even when HEAD matches. Keep distinct evidence and credit the report that established it.

Preserve disagreements that affect how the author should verify a challenge. Include the evidence needed to test each side and any behavior a fix must preserve.
